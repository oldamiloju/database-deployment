# database-deployment 
This project consists of me deploying and securing three databases using both native installation and Docker.

The databases are:

- PostgreSQL
- MySQL
- MongoDB


I learned:
- how to install and deploy postgresql, MySQL and mongodb both natively and with docker
- how to create databases with usernames and passwords
- how images, containers and port mapping works
- how to use git and github to manage projects like this
- how to troubleshoot
